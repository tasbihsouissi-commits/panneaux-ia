# Modèles

Les poids entraînés (`.pt`, `.pth`) sont volumineux et exclus du dépôt par `.gitignore`. Ils seront conservés localement sous `models/` ou dans un stockage externe autorisé.

Pour chaque modèle partagé, documenter ici : architecture, jeu de données et division, configuration/commande, versions logicielles, date, métriques et lien de téléchargement si disponible. Ne pas présenter des poids préentraînés comme un résultat entraîné par le groupe.
